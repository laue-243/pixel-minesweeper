# Pixel Minesweeper

Classic Minesweeper with pixel art style.

## How to Play
Open `index.html` in any browser. Click to reveal squares. Right-click to flag mines. Clear the board without hitting a mine!

## Features
- Pure client-side — no dependencies or build step
- Pixel graphics
- Flagging and first-click safety
- Timer and mine counter

Part of the pixel games collection by laue-243.
